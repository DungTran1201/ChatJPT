# Exam & Reference Materials Management Documentation

Thư mục tài liệu kỹ thuật chuẩn mực cho phân hệ Quản Lý Kho Đề Thi & Tài Liệu Tham Khảo (JLPT N5..N1, Kaiwa, Tae Kim Grammar Guide, Từ Điển Tiếng Nhật).

## Cấu Trúc Tài Liệu
- `00-scope-assumptions-decisions.md`: Phạm vi nghiệp vụ, giả định và quyết định kiến trúc.
- `01-feature-inventory-and-traceability.md`: Danh mục chức năng và ma trận truy vết (`FR-074` .. `FR-078`).
- `02-srs-exam-management.md`: Đặc tả yêu cầu phần mềm chi tiết.
- `03-use-cases-and-acceptance-criteria.md`: Use case (`UC-045` .. `UC-047`) và tiêu chí nghiệm thu.
- `04-domain-model-and-data-dictionary.md`: Mô hình thực thể và từ điển dữ liệu 3 bảng CSDL.
- `05-architecture-and-api-contract.md`: Kiến trúc thành phần và hợp đồng API RESTful.
- `06-ux-ia-and-user-flows.md`: Kiến trúc thông tin trang `/exams` và luồng thao tác người dùng.
- `07-mermaid-diagrams.md`: Biểu đồ tuần hoàn (`SEQ-016`) và biểu đồ thành phần (`COMP-006`).
- `08-security-and-risk-review.md`: Đánh giá an toàn thông tin và chống gian lận đề thi.
- `09-test-plan-and-test-cases.md`: Kế hoạch kiểm thử và ma trận ca kiểm thử (`TC-EXAM-001` .. `TC-EXAM-006`).
- `10-open-questions-and-implementation-readiness.md`: Câu hỏi mở và danh sách kiểm tra sẵn sàng.
